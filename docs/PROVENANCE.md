# Vydykhai Origin And Provenance

This page records the public evidence trail for Vydykhai. It is a provenance record, not a claim that copyright covers general ideas or methods.

## Origin

Vydykhai was conceived, directed, named, and originally published by Alexander Rozhnov (Александр Рожнов). AI systems assisted with research, drafting, editing, and implementation under his direction. The canonical repository is:

<https://github.com/vonjor-lab/vydykhai-humans-as-agents>

The GitHub repository was created on 2026-06-20. The earliest commit in its current canonical history is dated 2026-06-27.
