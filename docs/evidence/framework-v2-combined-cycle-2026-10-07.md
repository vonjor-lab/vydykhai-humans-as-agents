## Repairs Derived From Evidence

- Independent preflight tightened the harness: actual required-source acquisition,
  exactly one completed native turn, successful registered command result, stable
  source observations and exact continuation output are required, not CLI exit.
- A separate real-command counterexample showed premature COMPLETED observation
  before final context readback. The runner now observes completion only after
  final success; source drift after an effect stays IN_FLIGHT/UNKNOWN, not replayable.
- Review allocations can pin `scope.requiredSourceIds`; unread required sources
  refuse verdict publication. This is acquisition evidence, not semantic infallibility.
- The candidate observer now has optional deterministic continuation for a trusted
  grant's exact stored execution request. It cannot plan, grant itself permission,
  renew expiry or accept product work. Ordinary grants are not opted in. Tests
  exercise installed-process execution, restart without replay, pause, expiry,
  mismatched bindings and unknown effects. This change postdates the frozen run.

The combined task did not perform an actual owned repair within the same native
cycle. Separate prior repair evidence remains separate. Final independent review,
complete supported installation/operation and a comparable bounded canary remain
release gates; do not relabel this developmental experiment as their completion.
