Status: LIMITED_PASS, NO_RELEASE. Synthetic data only. Two separately approved
Sol 6.1 High runs, each capped at 120 seconds, no retries and no Astra. Neither
run changed a file, touched a product nor dispatched work. This qualifies a narrow
preparation/review policy slice, not the complete operating system.

## Setup And Evidence

`tests/fixtures/framework-v2-pilot` contains an ordinary quotation-export request,
public capability map/contracts, entity-linked memory, current and superseded
decisions, assisted Lab history, retained ideas and current ownership. The normal
request does not name the decision files or the omitted obligations.

`scripts/stage-v2-pilot.mjs` freezes sources, places original project evidence in
separate preparation/review workspaces and keeps the oracle outside both. The
reviewer sees a prewritten plausible but incomplete proposal, not the preparer's
answer. Its independent source route is unrestricted within the synthetic project.
Expected criteria were frozen before either run; final scoring is by the maintainer
against meaning/evidence, not keyword presence or another model judge.

Local no-model sandbox preflight established readable project sources, denial of
outside-oracle access and denial of workspace writes. An initial preflight harness
failed to handle a non-POST request; a second lacked denied-tool receipt coverage.
Both were harness diagnostics, not model failures or billed retries. The corrected
probe captured actual denials before either paid invocation. Phase input hashes
matched after both runs. No tool-driven network or producer source was supplied.

## Limits And Next Gate

This small coherent fixture allowed reading nearly every source. It does not prove
selective retrieval on a long tangled graph, cheap-model preparation, autonomous
review initiation, sustained drift resistance, shared memory updates or real branch
cleanup. No implementation/repair/second-task closure was performed by a model.
The rubric author also scored the results; an independent adjudication is absent.

Next: qualify the implemented host lifecycle and an isolated existing-project
snapshot with independently checked coverage, ordinary questions and no live
credentials. Preserve any missing/private source limitations and snapshot-to-live
deltas before a bounded canary. Do not use this result to install the full candidate.

Related mechanical work: `debt-progress.mjs` compares original cohorts, discovery,
created debt, independent closure, due/stagnant windows and product outcomes. It
rejects disappearance/relabeling, unrecorded deadline changes and self-certified
closure. Recovery consumes adverse supplied debt windows before a completion
claim. These are trusted-input deterministic checks, not semantic proof or a live
trend collector. Full repository verification: 433/433 tests, framework validator
PASS at 1.34.1, diff check PASS.

Evolution gate: Benefit = concrete evidence of unhinted source-backed planning and
independent rejection of an attractive incomplete packet. Complexity = short policy
slice and reusable isolated fixture, no production actor or timer. Verdict = proceed
with bounded qualification; DEFER RELEASE and make no economy/general-reliability claim.
