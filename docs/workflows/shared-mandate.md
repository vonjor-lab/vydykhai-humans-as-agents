# Shared mandate

The orchestrator owns the user's DOD, scope, course and return within actual authority. Prepare once against originals and keep the same executor through delivery. Change approach before escalating model capability. Retain failed attempts, spend, explicit pauses and UNKNOWN effects without replay. Use one bounded terminal-event wait. Where the host nests a wait in an outer tool call, give the outer call time to reach the same event or deadline; an early yield can reload the full manager context. At a safe ownership boundary, if repeated large inputs dominate cost, switch the manager working view to the DOD, commitments, pauses, effect/spend ledger and original links. Preserve full history and the same executor. Attribute manager, executor and auditor costs separately. When a host cannot prove delivery or enforcement, record LIMITED, the owner and the recovery path.

Independent REVIEW uses a fresh context and a reviewer who did not produce the work. Start from the last accepted state, try to disprove each material claim using originals and record what the evidence supports or leaves open. A clean verdict is valid. Reopen only changed claims, evidence or risks. Scope a hold to dependent use or the affected action. Protected admission, PRE/POST/HEALTH and human authority continue under their existing contracts.

Use the memory graph in both directions from affected decisions through module contracts to consumers and back to original evidence. Retain source, status, reason, owner and authority. Distinguish never recorded, missing from a scoped search, and recorded but unapplied. Keep ideas and deferred commitments with return conditions outside active work.

At manager rotation, reconstruct goal, obligations, pauses, decisions, ideas, spend, effects, source links, owner and course from originals. Obtain one bounded fresh comparison against the accepted state before the human-confirmed switch to one owner. Track project health (resources, branches and debts) separately from manager health (lost obligations, failed returns and coordination cost). A material event or due obligation triggers the applicable check. Routine green status requires no daily model call. Treat file access and a real open/continue callback, addressed event delivery, and separately permitted background scheduling as distinct harness capabilities. Keep foreground available when the host lacks a verified independent runner. On “pause Guard”, retain Project Guard: PAUSED in Project State; resume only on explicit direction.
