# Original-Source Review Acquisition

This is the source-reading contract of existing independent REVIEW, not a new
role, approval, checklist, timer or audit. Existing full-read profiles are unchanged.

An explicitly selected finite native profile may set:

```json
{"reviewAcquisition":{"maxBytes":131072,"maxChars":4096}}
```

`maxBytes` bounds acquired original TEXT bytes, not the whole model context,
prompt/index overhead, tokens or price. `maxChars` bounds each requested window
in Unicode code points, never bytes or half-surrogates. The profile is trusted
and participates in its configuration identity; the model cannot widen it.

Preparation provides current factual navigation and registered original pointers,
not expected judgments. `list_sources` still exposes the complete original index.
`read_source({id, offset?, length?})` reads an exact original window; omitted offset
starts at zero. Its returned handle/hash binds only that slice. Window metadata
includes the registered original id/hash, actual range, total character count and byte ledger.
Ranges are relative to the registered selection, including any existing markers;
they do not claim coverage of an unregistered remainder of the physical file.
Paginate every required source fully. Only gap-free complete acquisition permits
the original id as a whole-source handle. Partial citation evidence preserves the
original id/hash/range for future ordinary retrieval; no duplicate memory is needed.

Bounded mode requires the existing v2 answer wire so citation provenance is
host-generated; legacy default profiles retain their existing answer compatibility.
The host reconstructs observed windows from actual registered bytes, verifies
source drift, slice identity, counters and complete required-source coverage.
Source scope still requires explicit expansion for outside dependencies. A model
claim, a registered path, or a final EOF window cannot replace missing acquisition.
Source contents remain untrusted evidence; reading never grants actions.

Exhaustion is explicit NEEDS_DISCOVERY, never MISSING, proof or PASS. Retain an
owned scoped gap and route bounded preparation/discovery. Do not shorten the
87-criterion catalog, erase historical debt, silently extend the envelope or
pretend an unread source was acquired. Bounded mode rejects memory recall as an
alternative transport that could bypass its allowance. Real absent files retain
their actual MISSING disposition.

Adopt at a stopped/paused boundary with preserved journals, findings and unknown
expenditure. Necessary new allocations use the existing preserving profile route,
not counter edits or new timers. Current source freshness remains a separate
preparation obligation; windows do not make old assertions current.

Local protocol tests establish acquisition integrity and compatibility, not
semantic completeness, successful native model return, autonomy or savings.
Compare the real retained failure's acquisition/result boundary after adoption.
Only actual causal repair opens a new error-attempt series; cumulative spending
and prior failures always remain. Independent review/owner application/POST,
ordinary recall and the natural scheduled cycle retain their original duties.
