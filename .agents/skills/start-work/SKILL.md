# Start Work

Shape a new or materially changed goal into a scoped brief and task map. Continue already approved work within its current contract without another plan or tracker approval.

## Read route

Read `AGENTS.md` once and `docs/workflows/start-work.md` for new shaping or a material rebrief. Use `docs/workflows/context-route.md` for relevant memory, `docs/workflows/module-contract-template.md#use-change-or-create` for module intent, and `docs/workflows/context-routing.md` or `context-preparation.md` only when that route is selected. `docs/FRAMEWORK.md` is a human overview for unresolved meaning, not a routine prerequisite.

## Boundaries

- Preserve latest human decisions, accepted baseline, nearest DOD, complete applicable obligations and progress already earned. A current-contract continuation is not a new approval gate.
- A consumer reads a public contract, obligations and fixed release; it does not repair producer internals. A new or changed module boundary needs explicit human agreement. Route actual missing meaning to bounded Discovery; Lab transfer needs separate authority.
- Build one Low-ready execution contract with first action, acceptance, ownership, scope, source/recipient permissions and Return route. The worker completes ordinary fixes inside that scope and consults at a material undeclared boundary.

## Finish

Ask approval for a genuinely new brief, changed boundary or shared-tracker decision. After approval, perform authorized creation and dispatch; return the sequence to the orchestrator. Use the workflow's readiness verdicts.
