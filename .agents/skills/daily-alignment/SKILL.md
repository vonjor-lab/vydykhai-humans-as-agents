# Daily Alignment

Reconcile a meaningful external event that changes another participant's safe next action. Routine progress, task-local failure and current-contract continuation stay on their existing routes.

## Read route

Read `AGENTS.md` once and `docs/workflows/daily-alignment.md` when this event qualifies. Use the relevant source and current control snapshot. `docs/FRAMEWORK.md` is a human overview for unresolved meaning, not a routine prerequisite.

## Boundaries

Preserve source precedence, direct human control and unaffected work. Only the assigned orchestrator updates shared state or issues a traceable delta. Missing participant evidence limits overlapping work, not independent authorized work. Keep meeting details out of task contexts; send only the actionable, accepted delta. Follow the workflow's return and finish rules.
